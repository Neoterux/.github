# Contributing

Thanks for your interest in contributing! 🤗

## Before you start

- Search the existing open and closed issues to avoid duplicates.
- For anything larger than a small fix, open an issue first so the change can be discussed.

## Reporting bugs and requesting features

Use the issue templates provided in the repository:

- **🐛 Bug Report** — something isn't working as expected.
- **✨ Feature Request** — a new feature or enhancement.

## Submitting a pull request

1. Fork the repository and create a branch from the default branch.
2. Keep each pull request focused on a single change (docs, feature, fix, etc.).
3. Follow the existing code style of the project.
4. Update the documentation if your change requires it.
5. Make sure the tests pass before opening the pull request.
6. Fill out the pull request template and reference any related issue (e.g. `Closes #123`).

## Code of Conduct

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
